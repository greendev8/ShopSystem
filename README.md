# Shop System

A shop system I made for fun :D

# Features

 - Camera manipulation for a more cinematic perspective
 - Implements a variety of GUI objects and functions through them
 - Highlighting purchasable items when hovering (working with mouse)
 - Uses a coins currency system and a fruits item system with specific values
 - Works with leaderstats

# Dependecies

 - The open/close system works with a proximity prompt inside of an npc
 - The highlighting works with a market stand model my friend made (it has fruits in it that the scripts reference to apply a highlight to them)
 - The entire system works with together with a GUI I made (I attached it as a model)
 - The connection from the client to the server is made through a remote event called "UpdateStats" , located in ReplicatedStorage
